## Phase 1 — Stabilize the existing website

Acceptance criteria:
- [ ] Homepage visually reviewed at 1440, 1280, 1024, 768, 390 and 375 widths.
- [ ] No horizontal overflow.
- [ ] Keyboard/focus states verified.
- [ ] Image alt text reviewed.
- [ ] All buttons/links have intentional destinations.
- [ ] WhatsApp/contact actions tested.
- [ ] Navigation behavior verified on mobile.
- [ ] Footer links verified.
- [ ] FAQ interaction verified.
- [ ] No fake proof appears anywhere.

1. service detail pages
2. industries

5. insights
6. contact
