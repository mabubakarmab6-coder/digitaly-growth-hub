# DigitalyMarket SEO Bible

## Current verified foundation

The homepage currently defines:
- title: `DigitalyMarket | Digital Growth Agency for Modern Businesses`
- meta description targeting manufacturers, B2B companies, service businesses and e-commerce brands
- Open Graph title/description/type/url
- Twitter card metadata
- canonical link
- ProfessionalService JSON-LD
- founder and service-area information in structured data

The services page also defines title, description, canonical URL, social metadata and ItemList JSON-LD.

## Core search themes

Primary themes:
- digital marketing agency
- GEO services
- generative engine optimization
- paid marketing
- website development
- e-commerce growth
- B2B digital marketing
- manufacturer marketing
- digital marketing for small businesses

These should be used naturally, not stuffed.

## On-page rules

- One H1 per page.
- Use logical H2/H3 hierarchy.
- Write descriptive page titles and meta descriptions.
- Use descriptive image alt text.
- Use internal links where they genuinely help users.
- Make every indexable page useful enough to deserve its own URL.

## Technical SEO launch checklist

- [ ] Replace Lovable canonical/production URLs with the custom domain.
- [ ] Verify robots.txt for the final domain.
- [ ] Generate/verify sitemap.
- [ ] Verify canonical tags on all final pages.
- [ ] Configure Open Graph image(s).
- [ ] Validate JSON-LD.
- [ ] Connect Google Search Console.
- [ ] Submit sitemap.
- [ ] Confirm indexability.
- [ ] Verify 404 behavior.
- [ ] Test redirects and canonicalization.
- [ ] Check mobile Core Web Vitals/performance.

## Important current mismatch

The services JSON-LD references `/services/geo`, `/services/paid-marketing`, `/services/web-creation`, and `/services/ecommerce-growth`, but those route files are not currently present. Do not leave structured data pointing at non-existent pages.

## GEO strategy

DigitalyMarket's GEO strategy should focus on entity clarity, topical authority, useful expert content, structured data, strong internal linking and genuinely helpful answers to business questions. Avoid treating GEO as a magic keyword tactic.

## SEO/GEO content standard

Every article should demonstrate experience, expertise, authority and trust through original reasoning, transparent examples, practical frameworks and accurate claims.
